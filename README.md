# NO MAN'S CITY

Pracovni repozitar pro webovou open-world hru NO MAN'S CITY.

## Aktualni cil
Nejdriv stabilni technicky zaklad: mapa, pohyb, kamera, kolize, lane-based doprava a policejni routing. Teprve potom dalsi gameplay vrstvy.

## Deployment
Projekt je pripraveny pro staticky hosting. Velke binarni GLB assety se budou drzet mimo bezny Git commit, protoze hlavni mapa ma pres 100 MB a prekrocuje limit GitHubu pro bezny soubor.
